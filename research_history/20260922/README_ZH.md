这些是不同时间、机器和配置下的研究记录，不合并为一张统一性能排行榜。

## 数字如何解释

- BVE 的 MC 配对试验：556 模型、3 个种子，共 1668 个观测；共同可解几何比 0.958，
  总求解观测 1439/1445（候选/基线）。典型时间改善不能抵消覆盖损失。
- 同类 rIC3 配对试验：1668 个观测，几何比 0.972，求解观测 1486/1486，
  独有/丢失各 4。观测数不是独立模型数。
- CNF best-origin 报告给出 41742 条重放结果；单次冻结查询的映射效应通常小于轨迹效应，
  而且包含交互作用。单线程轨迹解释不能直接代替四线程端到端收益。
- 331 模型六策略筛选只有两个 candidate-only 结果。筛选成功和正式可验证突破应分开，
  应继续查确认目录及见证/证书，不能仅凭该表宣称扩大正式覆盖。

## 完整性与范围

`manifest.tsv` 记录原工作区相对路径、原文件 SHA256、导出文件 SHA256。
导出时仅把 `/home/用户名/` 统一为 `<WORKSPACE>/`，没有修改时间、状态或计数。
路径规范化后的脚本是历史分析材料，运行前需配置工作目录及依赖；本包不声称是
独立、无需配置的完整复现实验 artifact。输入模型及求解器二进制不在本目录。

未收录大型 SAT trace、完整日志、第三方电路源码或可执行文件。CNF trace 在原工作区
压缩保留，成员和归档 SHA256 清单随本存档提供；因此 GitHub 结果表备份不等于
完整 trace 备份。任何依赖原 trace 的新分析仍需取得对应归档。

较早报告和后续确认并列保存，用报告描述的样本、时限和复核条件解释结果。
筛选偏差、并发负载、共同可解条件和随机种子影响都应保留，不能只摘取最好的速度比。
